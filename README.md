# 📡 Laser-Based Communication Using Satellite (MATLAB Simulation)

## 📌 Overview
This project simulates a **laser-based satellite communication system** using MATLAB, where visual data (images) are transmitted as **laser pulses** between a transmitter and receiver via a satellite link. The system demonstrates **high-speed, secure optical communication** by converting image data into a pulse train, modulating it using **External Amplitude Modulation (EAM)**, and reconstructing the original image at the receiver.

---

## ❗ Problem Statement
Traditional radio frequency (RF) communication systems face limitations such as:
- Limited bandwidth  
- Signal interference  
- Lower data rates  

There is a growing need for **high-speed, secure, and efficient communication systems**, especially for satellite and space applications.

This project explores **laser-based optical communication** as a next-generation solution.

## 🎯 Project Objectives
- Convert image data into a train of optical pulses

## 🧠 System Architecture

### 🔧 Main Components (Simulation Level)
- **Input Image Module** – Converts image into digital signal  
- **Pulse Generation Module** – Converts data into laser pulses  
- **Modulation Unit (EAM)** – Modulates laser beam  
- **Satellite Channel** – Simulates transmission medium  
- **Receiver Module** – Detects incoming pulses  
- **Reconstruction Module** – Rebuilds original image  

---

## ⚙️ Working Principle

1. An input image is converted into **digital binary data**  
2. The binary data is transformed into a **train of laser pulses**  
3. The pulses are modulated using **External Amplitude Modulation (EAM)**  
4. The modulated signal is transmitted through a **simulated satellite link**  
5. The receiver captures the incoming optical signal  
6. The signal is demodulated and processed  
7. The original image is **reconstructed from the received data**  

---

## 🔄 Workflow

Image Input → Binary Conversion → Pulse Generation → EAM Modulation → Satellite Transmission → Signal Reception → Demodulation → Image Reconstruction
